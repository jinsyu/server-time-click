# 서버 시각 클릭

예매 사이트의 **서버 시각**을 0.01초 단위로 보여 주고, 원하면 오픈 시각에 **지금 마우스가 있는 자리를 딱 한 번 클릭**하는 Windows / macOS 프로그램입니다.

로그인·좌석 선택·결제는 하지 않습니다. 시계를 보여 주고, 정해진 순간에 클릭 한 번만 합니다.

## 내려받기

[Releases](../../releases/latest)에서 받으세요.

| OS | 파일 |
| --- | --- |
| Windows 10/11 (64비트) | `servertime-windows.exe` |
| macOS 11 이상 (Apple Silicon·Intel 공용) | `ServerTimeClick-macos.zip` |

## 쓰는 법

1. 프로그램을 켜면 기본 주소(NOL 티켓, `https://poticket.interpark.com/`)의 서버 시각을 자동으로 맞춥니다.
   예매하는 사이트가 다르면 **주소**를 바꾸고 `시각 다시 맞추기`를 누르세요.
2. **오픈 시:분:초**를 목록에서 고릅니다(한국 시간). `다음 정각`, `연습: 1~2분 뒤` 버튼으로 빠르게 고를 수도 있습니다.
   아래에 "오늘 / 내일 몇 시, 얼마 뒤"가 표시되니 날짜가 맞는지 확인하세요. 이미 지난 시각은 내일로 잡힙니다.
3. **클릭 지연(ms)**: 오픈 시각보다 몇 ms 늦게 클릭할지입니다. 기본값은 `50`입니다.
   너무 정확하면 예매 버튼이 바뀌기 직전에 눌릴 수 있어서 조금 늦게 누릅니다. 연습해 보고 그래도 이르면 100, 150처럼 늘리세요.
4. `예약`을 누릅니다.
5. **브라우저를 한 번 클릭해 앞으로 가져오고**, 마우스를 예매 버튼 위에 올려 둔 채 손을 뗍니다.
   이 프로그램 창이 앞에 있으면 "브라우저를 클릭해 앞으로!" 경고가 뜹니다.
6. 10·3·2·1초 전에 소리가 나고, 정해진 순간에 한 번 클릭합니다. 기록 창에 실제 클릭한 서버 시각과 목표와의 차이가 남습니다.

**본 예매 전에 1~2분 뒤 시각으로 꼭 한 번 연습해 보세요.**

### Windows

- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 `추가 정보` → `실행`.
- 브라우저를 관리자 권한으로 실행했다면 이 프로그램도 관리자 권한으로 실행해야 클릭이 들어갑니다.

### macOS

1. zip을 풀고 `ServerTimeClick.app`을 응용 프로그램 폴더로 옮깁니다.
2. 처음 열 때 "확인할 수 없는 개발자" 경고가 뜨면, 시스템 설정 → 개인정보 보호 및 보안 맨 아래 `그래도 열기`를 누릅니다.
   또는 터미널에서:
   ```bash
   xattr -dr com.apple.quarantine /Applications/ServerTimeClick.app
   ```
3. `예약`을 처음 누르면 **손쉬운 사용** 권한을 요청합니다. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 `ServerTimeClick`을 켜고, **앱을 완전히 종료(⌘Q)했다가 다시 여세요.**
   권한이 없으면 macOS가 클릭을 조용히 무시합니다.
4. 새 버전으로 바꾸면 권한을 한 번 껐다가 다시 켜 주세요.

## 서버 시각을 맞추는 방법

따로 쓰는 시간 서버는 없습니다. 예매 사이트에 요청을 보내면 응답 헤더 `Date:`에 그 서버의 시계가 초 단위로 적혀 옵니다.

초 단위라도, "요청을 보낸 순간(t0)과 응답을 받은 순간(t1) 사이 어딘가에서 서버 시계가 D였다"는 사실에서
`서버 − 내 컴퓨터` 차이는 `[D − t1, D + 1 − t0]` 범위 안에 있습니다.
요청을 보내는 순간을 현재 추정치의 초 경계에 맞추면 이 범위가 매번 절반씩 줄어듭니다(이진 탐색). 12번이면 보통 오차가 왕복 시간 이하로 줄어듭니다.

- 캐시된 응답(`Age`, `X-Cache: Hit`)은 버립니다.
- 다른 응답들과 안 맞는 응답은 1~2번은 무시하고, 3번 연속이면 처음부터 다시 맞춥니다.
- 켜 둔 동안 15초마다 다시 재서 맞추고, 클릭 5초 전부터 2초 후까지는 요청을 보내지 않습니다.
- 내 컴퓨터 시각은 고정밀 단조 카운터(Windows는 QueryPerformanceCounter)로 재서, 실행 중에 OS가 시계를 고쳐도 흔들리지 않습니다.
- 클릭 0.3초 전부터는 쉬지 않고 시각을 확인하다가 정확한 순간에 클릭합니다.
- 실행 중에는 컴퓨터가 잠들지 않게 하고, macOS에서는 App Nap도 막습니다.

## 직접 빌드

Go와 C 컴파일러(Windows는 MinGW-w64, macOS는 Xcode 명령줄 도구)가 필요합니다.

```bash
go test ./internal/...
go build -ldflags "-H windowsgui" -o servertime.exe .   # Windows
go build -o servertime .                                # macOS
```

macOS 릴리스 파일은 GitHub Actions(`.github/workflows/build.yml`)가 만듭니다.

## 주의

예매 사이트 약관은 보통 자동화 도구 사용을 금지합니다. 클릭 기능을 쓸지는 본인이 판단하세요. 시계만 보는 데는 클릭을 끄면 됩니다.
